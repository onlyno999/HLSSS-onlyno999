# HLSSS-onlyno999

婚礼三生三世情缘 30 秒短片专用生产 Agent（HL=婚礼、SSS=三生三世）：上传男、女各一张三视图锁脸演三世——古风仙侠结缘分离 → 民国重逢错过 → 现代婚礼走向礼堂、交换戒指、亲吻结束；调用 H3pro-onlyno999 全流程生产（定妆→九宫格→三锚→派发→质检→拼片→门禁）。

## 技能结构

- `SKILL.md` — 技能正文（v1.1.0 通用版）：触发与输入、开工咨询问卷（逐段时长/年代场景/逐段剧情/现代世过程线/结局/信物/对白/画幅，未确认不开拍）、片型骨架（样片默认值）、第三世过程线专规（相识→恋爱→求婚→殿堂＋时长伸缩）、对白默认模板、三世定妆专规、提示词铁律（官方英文六段式、只有台词中文）、派发挂法、探针警告、质检门
- `references/prompt_example_en_s1.md` — 英文提示词实测样例（S1 古风世，Ref2VA 六段式原文节选）
- `references/case_2026-10-03_sample.md` — 成功案例：2026-10-03 样片全流程实证（任务号/门禁数据）与两条教训（中文提示词抓包、探针误耗 333 币）

## 使用

把 `SKILL.md` 与 `references/` 放入技能目录（本地：`~/workspace/skills/hlsss-onlyno999/`）后，用户上传男女三视图并说「三生三世」即触发；Agent 先走开工咨询确认可自定义项（跳过用样片默认值）再生产。生产依赖本地 `h3pro-agent`（H3pro-onlyno999）技能与 RunningHub v2.5 派发链。
